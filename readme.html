N NIM LAB使い方ガイド

オンラインで遊ぶ（おすすめ）

インストール不要・登録不要で、下のリンクからそのまま遊べます。

NIM LAB を開く →

使い方

  1. 上のリンク（またはローカルの index.html）を開きます。
  2. 山の数・各山のコイン枚数・先手/後手を設定します。
  3. 「この盤面で始める」を押すと対局がスタートします。

ローカルファイルで使う場合

index.html をダブルクリックするだけで、ブラウザーが開いてそのまま対局を始められます。インターネット接続やインストールは不要です。

Googleドライブで使う場合

  • Google Drive for desktop の同期フォルダにこのフォルダを置けば、同期フォルダ内の index.html をダブルクリックして使えます。
  • ブラウザー版Googleドライブは、安全上の理由からHTMLアプリをその場で実行しません。ブラウザー版から使う場合は、このフォルダをダウンロードしてから index.html を開いてください。

オンライン版を使えば、この手順は不要です。

内容

  • 山の数と各山のコイン枚数を設定
  • 先手／後手を選択
  • 必勝手をすべて表示
  • 二進数とニム和を確認
  • 相手の手を手動入力
  • 対局後に全手を振り返り
NIM LAB — 勝ち筋を、目で理解する。
