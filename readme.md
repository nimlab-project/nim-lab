# NIM LAB

ニム（Nim）というコイン取りゲームの必勝法を、手を動かしながら理解するための対局・学習アプリです。

**公開URL:** https://nimlab-project.github.io/nim-lab/

## これは何か

ニムは、複数の「山」に分かれたコインを、プレイヤーが交互に1つの山から好きな枚数（1枚以上）取っていき、最後の1枚を取った人が勝ちというゲームです。実は「ニム和（各山の枚数をXORした値）」を常に0に保てば必ず勝てる、という数学的な必勝法が存在します。

NIM LABは、その必勝法を

- 二進数への分解
- 各山のXOR（ニム和）計算
- 必勝手の一覧表示

という形で可視化し、実際に対局しながら体で覚えられるようにしたものです。

## 主な機能

- 山の数（2〜8個）と各山の枚数（1〜255枚）を自由に設定
- 先手・後手を選んで対局開始
- 現在のニム和と、そのニム和を0にする必勝手をすべて提示
- 盤面を「コイン表示」「二進数表示」で切り替え可能
- 対人戦を想定し、相手の手（山と枚数）を手動入力
- 山の枚数がすべて偶数個ずつペアになった対称局面では、以降の最適手を自動で省略して勝敗を確定
- 対局後に全手を振り返れるレビュー画面（各手の前後比較、二進数分解、最善手かどうかの判定）
- 対局中はいつでも「戻る／進む」でundo・redoが可能

詳しい操作手順は [readme.html](./readme.html) を参照してください。

## 技術構成

- 依存ライブラリなしの単一HTMLファイル（`index.html`）
- Vanilla JavaScript（IIFE 1本、外部ビルドツール不要）
- GitHub Pages でホスティング（`master` ブランチのルートを配信）
- ローカルでも `index.html` をブラウザで直接開くだけで動作（インターネット接続不要）

## ファイル構成

```
index.html    アプリ本体（このファイルだけで動作する）
readme.html   使い方ガイド（ブラウザで読む用）
readme.md     このファイル（プロジェクトの説明）
```

## 対象プレイの前提

「Normal Play」ルール（最後の1枚を取った人が勝ち）を採用しています。
